# UI Contract: macOS Pomodoro Timer App

**Date**: 2026-04-06

## Menu Bar Item

상단 메뉴바에 항상 표시되는 요소.

### 표시 형식

| State | Display |
|-------|---------|
| Idle (작업 미선택) | `🍅` (토마토 아이콘) |
| Idle (작업 선택됨) | `🍅 업무명` |
| Focus 진행 중 | `🍅 24:59` 또는 `🍅 업무명 24:59` |
| Focus 일시정지 | `🍅 ⏸ 24:59` |
| Short Break | `☕ 4:59` |
| Long Break | `☕ 14:59` |

- 업무명은 최대 15자, 초과 시 말줄임표(`...`)
- 시간 형식: `MM:SS`

## Popover (메뉴바 클릭 시)

### 레이아웃

```
┌─────────────────────────────┐
│  ⏱ 24:35       [⏸] [↺] [⏭]│  ← 타이머 영역 (진행 중일 때)
│  ── 포모도로 2/4 ──────────  │
├──────────────────────────��──┤
│  📋 오늘 할 일               │
│  ○ 09:00 팀 스탠드업 미팅    │  ← 캘린더 이벤트
│  ● 디자인 리뷰              │  ← 선택된 항목 (●)
│  ○ 14:00 코드 리뷰          │
│  ○ 보고서 작성 (수동)       │  ← 수동 입력 항목
│  ─────────────────────────  │
│  [+ 할 일 추가]              │
├─────────────────────────────┤
│  ⚙ 설정    종료              │
└─────────────────────────────┘
```

### 타이머 컨트롤 버튼

| Button | Action | Visible When |
|--------|--------|-------------|
| ⏸ / ▶ | 일시정지 / 재개 | Focus 진행 중 |
| ↺ | 리셋 (현재 세션 취소) | Focus 또는 Break 진행 중 |
| ⏭ | 스킵 (휴식 건너뛰기) | Break 진행 중 |

### 할 일 목록 상호작용

- 항목 클릭: 현재 작업으로 선택 (● 표시), 이전 선택 해제
- 선택된 항목 다시 클릭: 선택 해제
- 항목 왼쪽 스와이프 또는 완료 버튼: 완료 처리 (취소선)
- `+ 할 일 추가`: 텍스트 필드 표시 → 입력 후 엔터로 추가

## Global Shortcut Contract

| Action | Default | Customizable |
|--------|---------|-------------|
| 시작/일시정지 토글 | 없음 (사용자가 설정) | Yes |

- 단축키는 앱 전체에서 하나만 사용 (시작/일시정지 토글)
- 팝오버 내 리셋/스킵은 UI 버튼으로만 조작

## Notification Contract

| Event | Title | Body | Sound |
|-------|-------|------|-------|
| Focus 완료 | "포모도로 완료!" | "휴식 시간입니다 ☕" | Default |
| Short Break 완료 | "휴식 끝!" | "다음 포모도로를 시작하세요" | Default |
| Long Break 완료 | "긴 휴식 끝!" | "새로운 사이클을 시작하세요" | Default |
