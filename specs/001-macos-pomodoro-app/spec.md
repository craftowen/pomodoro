## User Scenarios & Testing *(mandatory)*

### User Story 1 - 단축키로 포모도로 즉시 시작/정지 (Priority: P1)

사용자가 어떤 작업을 하던 중 글로벌 단축키를 누르면 즉시 포모도로 타이머가 시작된다. 타이머가 실행 중이면 macOS 상단 메뉴바(status bar)에 남은 시간이 실시간으로 표시된다. 타이머 종료 시 알림이 울리고 휴식 시간으로 전환된다.

**Why this priority**: 포모도로 앱의 핵심 가치. 이 기능 없이는 앱의 존재 의미가 없다.

**Independent Test**: 앱 실행 후 단축키만으로 타이머를 시작/정지할 수 있고, 메뉴바에서 남은 시간을 확인할 수 있다.

**Acceptance Scenarios**:

1. **Given** 앱이 실행 중이고 타이머가 멈춘 상태, **When** 사용자가 글로벌 단축키를 누르면, **Then** 25분 포모도로 타이머가 시작되고 메뉴바에 남은 시간이 표시된다
2. **Given** 포모도로 타이머가 실행 중, **When** 25분이 경과하면, **Then** 알림(사운드 + 시스템 알림)이 울리고 5분 휴식 타이머로 자동 전환된다
3. **Given** 타이머가 실행 중, **When** 사용자가 글로벌 단축키를 다시 누르면, **Then** 타이머가 일시정지되고 메뉴바에 일시정지 상태가 표시된다
4. **Given** 4번의 포모도로가 완료된 상태, **When** 다음 휴식 시간이 시작되면, **Then** 15분 긴 휴식 타이머가 시작된다
5. **Given** 포모도로가 진행 중, **When** 사용자가 팝오버에서 리셋을 누르면, **Then** 현재 포모도로가 취소되고 대기 상태로 돌아간다
6. **Given** 휴식 타이머가 진행 중, **When** 사용자가 팝오버에서 스킵을 누르면, **Then** 휴식이 종료되고 다음 포모도로 대기 상태로 전환된다

---

### User Story 2 - 메뉴바에서 오늘의 할 일 확인 및 선택 (Priority: P2)

사용자가 메뉴바 아이콘을 클릭하면 팝오버 창이 열리고, 오늘의 할 일 목록이 표시된다. 할 일 항목을 체크하면 해당 업무명이 메뉴바에 현재 작업으로 표시된다. 이를 통해 "지금 무엇을 하고 있는지"가 항상 보인다.

**Why this priority**: 할 일 목록과 포모도로의 연결이 생산성의 핵심. 단순 타이머를 넘어 업무 추적이 가능해진다.

**Independent Test**: 메뉴바 클릭 시 할 일 목록을 보고, 항목을 선택하면 메뉴바에 해당 업무명이 표시된다.

**Acceptance Scenarios**:

1. **Given** 앱이 실행 중, **When** 사용자가 메뉴바 아이콘을 클릭하면, **Then** 오늘의 할 일 목록이 팝오버로 표시된다
2. **Given** 할 일 목록이 표시된 상태, **When** 사용자가 특정 항목을 체크하면, **Then** 해당 업무명이 메뉴바에 "현재 작업"으로 표시된다
3. **Given** 현재 작업이 선택된 상태에서 포모도로 시작, **When** 타이머가 실행 중이면, **Then** 메뉴바에 "업무명 - 남은시간" 형태로 표시된다
4. **Given** 할 일 목록에 항목이 없을 때, **When** 메뉴바 아이콘을 클릭하면, **Then** "오늘 예정된 일정이 없습니다" 메시지가 표시된다

---

### User Story 3 - 구글 캘린더 연동으로 할 일 자동 불러오기 (Priority: P3)

사용자가 구글 캘린더 계정을 연동하면, 오늘 날짜의 캘린더 이벤트가 자동으로 할 일 목록에 표시된다. 매일 자동으로 갱신되어 별도 입력 없이 오늘의 업무를 확인할 수 있다.

**Why this priority**: 수동 입력 없이 기존 일정 관리 시스템과 통합하여 사용 편의성을 높인다.

**Independent Test**: 구글 계정 로그인 후 오늘의 캘린더 이벤트가 할 일 목록에 자동으로 나타난다.

**Acceptance Scenarios**:

1. **Given** 구글 캘린더가 연동되지 않은 상태, **When** 사용자가 설정에서 구글 캘린더 연동을 시작하면, **Then** OAuth 인증 흐름을 통해 계정이 연동된다
2. **Given** 구글 캘린더가 연동된 상태, **When** 앱이 시작되거나 날짜가 바뀌면, **Then** 오늘의 캘린더 이벤트가 할 일 목록에 자동으로 표시된다
3. **Given** 캘린더에 종일 이벤트와 시간 지정 이벤트가 있을 때, **When** 할 일 목록을 조회하면, **Then** 시간 지정 이벤트는 시간순으로, 종일 이벤트는 목록 상단에 표시된다
4. **Given** 연동된 캘린더의 이벤트가 변경되었을 때, **When** 사용자가 목록을 새로고침하면, **Then** 변경된 내용이 반영된다

---

### Edge Cases

- 인터넷 연결이 없는 상태에서 구글 캘린더 동기화를 시도하면? 마지막 동기화된 캐시 데이터를 표시하고 오프라인 상태를 알린다
- 포모도로 진행 중 맥이 잠자기 모드에 들어갔다가 깨어나면? 경과 시간을 정확히 계산하여 타이머를 보정한다
- 메뉴바 공간이 부족할 정도로 업무명이 길면? 일정 길이 이상은 말줄임표(...)로 표시한다
- 사용자가 구글 캘린더 권한을 취소하면? 연동 해제 상태로 전환하고 재연동을 안내한다

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 macOS 상단 메뉴바(status bar)에 상주하는 네이티브 앱이어야 한다
- **FR-002**: 시스템은 사용자가 설정한 글로벌 단축키로 포모도로 타이머를 시작/일시정지할 수 있어야 한다
- **FR-015**: 사용자는 팝오버에서 진행 중인 포모도로를 취소/리셋할 수 있어야 한다
- **FR-016**: 사용자는 휴식 시간을 건너뛰고 즉시 다음 포모도로를 시작할 수 있어야 한다
- **FR-003**: 시스템은 메뉴바에 현재 타이머 상태(남은 시간, 일시정지, 휴식)를 실시간으로 표시해야 한다
- **FR-004**: 시스템은 포모도로(25분) → 짧은 휴식(5분) → 포모도로 반복, 4회 후 긴 휴식(15분) 사이클을 지원해야 한다
- **FR-013**: 시스템은 휴식 종료 후 다음 포모도로를 자동 시작할지 수동 시작할지 설정 옵션을 제공해야 한다 (기본값: 수동 시작)
- **FR-017**: 시스템은 설정에서 포모도로 시간(기본 25분), 짧은 휴식 시간(기본 5분), 긴 휴식 시간(기본 15분)을 사용자가 변경할 수 있어야 한다
- **FR-005**: 시스템은 타이머 종료 시 macOS 시스템 알림과 사운드로 사용자에게 알려야 한다
- **FR-006**: 시스템은 메뉴바 아이콘 클릭 시 오늘의 할 일 목록을 팝오버로 표시해야 한다
- **FR-007**: 사용자는 할 일 목록에서 항목을 선택하여 현재 작업으로 지정할 수 있어야 한다
- **FR-008**: 시스템은 현재 작업명을 메뉴바에 타이머와 함께 표시해야 한다
- **FR-009**: 시스템은 구글 캘린더 OAuth 인증을 통해 오늘의 이벤트를 할 일 목록으로 가져올 수 있어야 한다
- **FR-014**: 시스템은 구글 캘린더 연동 시 사용자가 가져올 캘린더를 선택할 수 있어야 한다 (복수 선택 가능)
- **FR-010**: 시스템은 모든 데이터(설정, 포모도로 기록, 캐시된 캘린더 데이터)를 로컬에만 저장해야 한다
- **FR-011**: 시스템은 수동으로 할 일을 추가/삭제할 수 있어야 한다 (캘린더 미연동 시에도 사용 가능)
- **FR-012**: 시스템은 macOS 로그인 시 자동 시작 옵션을 제공해야 한다

### Key Entities

- **포모도로 세션**: 시작 시간, 종료 시간, 연결된 작업, 완료 여부를 나타내는 단위
- **할 일 항목**: 제목, 출처(구글 캘린더/수동 입력), 시간 정보, 완료 상태, 선택 상태
- **포모도로 사이클**: 현재 포모도로 회차(1~4), 다음 단계(작업/짧은 휴식/긴 휴식)
- **사용자 설정**: 글로벌 단축키, 포모도로/휴식 시간, 알림 설정, 자동 시작 여부

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 사용자가 단축키 한 번으로 1초 이내에 포모도로를 시작할 수 있다
- **SC-002**: 메뉴바 타이머가 1초 단위로 정확하게 업데이트된다
- **SC-003**: 구글 캘린더 연동 설정을 2분 이내에 완료할 수 있다
- **SC-004**: 앱이 메모리 50MB 미만으로 동작하여 시스템 리소스에 부담을 주지 않는다
- **SC-005**: 사용자가 할 일 목록에서 작업을 선택하고 포모도로를 시작하기까지 3번의 클릭/키 입력 이내로 가능하다
- **SC-006**: 모든 데이터가 로컬에만 저장되며, 앱이 외부 서버로 사용자 데이터를 전송하지 않는다 (구글 캘린더 API 호출 제외)

## Assumptions

- 대상 사용자는 macOS 13(Ventura) 이상을 사용한다
- 구글 캘린더 연동은 선택 사항이며, 연동 없이도 수동 할 일 관리와 포모도로 기능을 완전히 사용할 수 있다
- 포모도로 기본값은 25분 작업 / 5분 짧은 휴식 / 15분 긴 휴식이며, 사용자가 변경할 수 있다
- 기본 글로벌 단축키는 앱에서 제공하되, 사용자가 원하는 키 조합으로 변경할 수 있다
- 통계/리포트 기능은 v1 범위에 포함하지 않는다 (최소 기능 원칙)
- 앱 배포는 DMG 또는 직접 빌드 형태이며, Mac App Store 배포는 v1 범위 밖이다
- OAuth 토큰은 macOS Keychain에 안전하게 저장한다
